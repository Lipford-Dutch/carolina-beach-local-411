# Carolina Beach Local Vendors and Beach Vibes Swag & 411

A fast, mobile-first local guide for building a Carolina Beach day without
turning vacation planning into a research project.

## Product Experience

- Three-minute route builder tuned for morning, midday, sunset, or night.
- Searchable, filterable directory with direct links to current official pages.
- Device-local route and swag saves with no account or tracking dependency.
- 2026 market, parking, boardwalk, amusement, and ocean-safety essentials.
- Responsive, keyboard-accessible interface with reduced-motion support.

## Local Development

Requirements: Node.js 22.13 or newer.

```powershell
npm install
npm run dev
```

Use `npm run test` for the production build and server-render smoke tests. Use
`npm run lint` for the TypeScript and accessibility-oriented lint pass.

## Content Policy

Guide details were checked against linked first-party sources in July 2026.
Hours, rates, weather, and seasonal schedules can change, so the interface
always directs visitors to the source before they leave.
